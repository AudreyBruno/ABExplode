ABExplode
=============

Ferramenta de diagnóstico de hardware: informações do sistema, sensores, placa de vídeo,
FPS estimado em jogos, detector de gargalo, overlay de FPS, benchmarks (CPU, GPU, memória e disco),
otimização (limpeza de memória e ajustes para jogos) e stress test de CPU / RAM / GPU.

REQUISITOS (WINDOWS)
- Windows 10 ou 11, 64 bits. Não precisa instalar o .NET (já vem dentro do .exe).
- Para temperatura e consumo da CPU, instale o driver PawnIO (uma vez só):
      winget install namazso.PawnIO
- Aceite o pedido de administrador ao abrir (necessário para ler os sensores).
- Se a temperatura/consumo da CPU não aparecerem, o menu lateral mostra o motivo e um
  botão CORRIGIR, que instala o PawnIO com um clique. Depois feche e abra o programa.
  Se instalou o PawnIO e mesmo assim não aparecer, reinicie o PC.

COMO USAR (WINDOWS)
- Abra o ABExplode.exe. Na primeira vez ele demora alguns segundos para iniciar.
- Se o Windows mostrar "O Windows protegeu o computador", clique em "Mais informações"
  e depois em "Executar assim mesmo" (o programa não tem assinatura digital paga).
- Overlay: Ctrl + Shift + O liga e desliga.

LINUX (64 bits, X11 ou Wayland)
Três formas, escolha uma (todas trazem o .NET embutido):
- AppImage (mais simples): baixe o ABExplode-x86_64.AppImage, dê permissão de execução
  (botão direito > Propriedades > Permitir executar, ou: chmod +x ABExplode-x86_64.AppImage) e abra.
- Flatpak (aparece no menu de aplicativos e atualiza junto com o sistema):
      flatpak install --user ABExplode.flatpak
  Precisa do repositório Flathub configurado (para baixar o runtime freedesktop na primeira vez).
- Executável avulso: extraia o ABExplode-linux-x64.tar.gz e rode ./ABExplode.
Se faltar alguma biblioteca ou ferramenta (sensores, smartctl...), o app diz o que é e oferece instalar.
Ações de administrador (otimizações, overclock, drivers) pedem a senha pela janela do sistema (pkexec).
No Linux o overlay é o MangoHud: o app configura e o Ctrl + Shift + O liga e desliga dentro do jogo.

OBSERVAÇÕES
- Placas NVIDIA mostram mais detalhes (VBIOS, limites de energia, CUDA).
- Configurações e histórico ficam em %AppData%\ABExplode (não vão junto com o .exe). No Linux, em
  ~/.config/ABExplode (no Flatpak, ~/.var/app/io.github.audreybruno.ABExplode/config/ABExplode).
- As notas de GPU do Benchmark no Linux são em Vulkan e não se comparam com as do Windows (Direct3D).
- Use os stress tests com o limite de temperatura ligado e boa ventilação.
